# covid19.gov.sc — Square Country COVID-19 archive

A full, responsive, multi-page static government website for the **fictional Government of Square Country**. The site depicts a pandemic-era portal frozen after the emergency response ended on **21 July 2023**.

## Run locally
Open `index.html` in a modern browser, or use VS Code **Live Server**. No install, build command or backend is needed.

## Publish
Upload all `.html` files and the `assets/` and `documents/` directories to your hosting root (e.g. GitHub Pages). Do not move individual pages without their shared assets.

## Features
- Fully linked static HTML pages and mobile navigation
- Accessible historical archive notices across every page
- Client-side search against all site pages
- Expandable FAQ sections
- Functional local-only form demo with no transmission
- Downloadable plain-text campaign materials
- Local SVG favicon and emblem; optional Google Fonts fallback

## Important
This is a fictional archival website, not a source of actual public health policy, legal or medical advice. All historical milestones and programme descriptions are illustrative.
